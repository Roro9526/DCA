Privacy Policy

What DCA Publisher does with data, in plain terms.

Effective: 2026-08-21 Scope: single-user personal tool Contact: romain.lefevre@modexpo.fr
Short version: DCA Publisher is a personal, single-operator tool. It generates investment-simulation videos on the operator's own computer and uploads them as private drafts to the operator's own TikTok account. It does not collect, sell, or share data about anyone else.

01What this is

DCA Publisher is a personal project built and operated by a single individual. It renders short videos illustrating dollar-cost-averaging investment simulations from public market data, then uses TikTok's Content Posting API to send those videos as private drafts to the operator's own TikTok account for manual review and publishing.

It is not a public service, does not have a website users sign up on, and is not distributed to other people. The only TikTok account it connects to is the operator's own.

02Data this tool touches

  • TikTok access & refresh tokens — issued by TikTok when the operator authorizes the app, stored only in a local file on the operator's own computer (tiktok_tokens.json), never transmitted anywhere except back to TikTok's API.
  • Market price data — public price history (from Yahoo Finance or local files), used only to draw the chart in the generated video.
  • The rendered video file itself — stored locally, uploaded only to the operator's own TikTok drafts.

No other personal data is collected. There is no analytics, no tracking pixel, no cookie, and no database of users — because there is exactly one user: the operator.

03Data sharing

Nothing is sold or shared with third parties. The only external service this tool talks to is TikTok's own Content Posting API, strictly to deliver the video the operator generated to the operator's own account.

04Retention & deletion

TikTok tokens are kept locally until revoked. The operator can remove access at any time either by deleting the local token file or by revoking the app's permission from within TikTok's own account settings. Revoking access does not affect videos already delivered.

05Changes to this policy

This page may be updated as the tool changes. Since there is a single operator and no mailing list, changes are simply reflected here with an updated effective date.
