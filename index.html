Personal project

DCA Publisher

Generates dollar-cost-averaging investment simulation videos and sends them as private drafts to a single TikTok account for review before posting.

Type
Single-user tool
Posts
Private drafts
Stack
Python

What it does

  • Simulates a monthly investment ("dollar-cost averaging") on a stock, crypto, or commodity using public price history.
  • Renders the simulation as a short vertical video.
  • Uploads the video to the operator's own TikTok inbox via the Content Posting API (video.upload scope) — always as a private draft, never posted automatically.
